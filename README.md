# 📊 全自訂多股策略競技場 (打臉自己或是證明自己)

一個基於 **Streamlit** 開發的高效能互動式多股票量化回測與參數窮舉掃描平台。本系統支援多個技術指標條件的自由勾選、正向/反轉（多空雙向）配置，並能與台股大盤（加權指數 `^TWII`）進行累積報酬率的即時走勢對抗。系統具備獨立的資料庫增量維護維運腳本、數據稽核獨立後台，並完整內建了雲端部署字體防破圖機制。

---

## 🚀 核心功能

*   **📊 多股對抗競技場**：支援同時選擇多檔股票標的，在同一時間軸下與台股加權指數（`^TWII`）進行累積報酬率的走勢對抗。
*   **📋 多空雙向條件組合**：內建四大核心技術指標，支援自由勾選並可獨立配置為「正向」或「反轉」策略（含均線交叉、量能爆量、RSI 超賣、MACD 柱狀體）。
*   **📐 嚴謹的量化回測引擎**：時序上嚴格執行「昨日觸發訊號，今日計算報酬」邏輯；並利用 `cumsum()` 向量化切割獨立交易波段（Trade ID），精準計算每筆交易的真實勝率與每日平均期望值。
*   **🔍 自動化參數窮舉掃描**：系統自動對所選指標參數進行區間窮舉掃描，精確計算期望值並標註最佳參數。
*   **🎨 雲端原生字體防破圖**：專為 Render 等 Linux 雲端環境設計。透過 `packages.txt` 自動在伺服器端安裝思源黑體，配合 `config.py` 的雙平台字體配對，保證網頁圖表之中文字體與負號（`-`）在**本地 Windows** 與**雲端 Linux** 部署時皆能完美渲染、絕不出現亂碼豆腐塊。
*   **🗃️ 獨立雲端數據稽核後台**：提供庫存健康度全局統計，並支援 Excel 風格動態明細抽查，利用 `@st.cache_resource` 與 `pool_pre_ping=True` 確保遠端連線安全穩定。
*   **✨ 智能資料增量維護**：採群組化合併請求，**全程僅發送 1 次網路請求** 抓取全量資料以防止 Yahoo 限流封鎖，並具備智能差額補件與記憶體去重防禦。
*   **📈 高階擴充就緒 (Advanced Ready)**：環境已完整預裝 `ta`（技術分析指標庫）、`scikit-learn`（機器學習模型）與 `plotly`（互動式動態圖表），為下一階段的策略升級奠定扎實基礎。

## 📁 專案架構

```text
├── app.py                  # 系統主程式 (Streamlit 介面與多股策略回測主流程控制)
├── config.py               # 系統字型初始化、環境變數與標的清單載入模組
├── engine.py               # 策略指標計算與回測引擎核心 (指標算力與交易波段切分)
├── data_loader.py          # 數據載入器 (支援 Postgres 優先、yfinance 線上備援與扁平化清洗)
├── insert_data.py          # 數據維護工具 (智能抗封鎖、動態差額補件排程腳本)
├── view_db.py              # 資料庫獨立主控台 (獨立連線遠端進行數據稽核與抽查管理後台)
├── packages.txt            # 雲端部署系統套件清單 (用於 Render 自動安裝 Linux 思源黑體)
└── requirements.txt        # 專案 Python 依賴套件完整清單
```

## 🛠️ 環境變數配置 (.env)

請在專案根目錄下建立 `.env` 檔案，用來動態擴充股票選單、維護目標與配置資料庫連線：

```env
# 1. 自訂選股與維護清單（以逗號分隔）
TICKERS=2330.TW,2317.TW,2454.TW,^TWII,1303.TW,1326.TW,NVDA,AAPL,TSLA

# 2. 資料庫連線字串（支援自動適配 psycopg2 驅動與 Render.com 等雲端託管服務）
DB_URL=postgresql://user:password@://render.com
```

## 💻 快速開始

### 1. 本地環境準備
請確保您的開發環境已安裝 Python 3.8+，並透過一鍵指令安裝所有系統依賴：

```bash
pip install -r requirements.txt
```

### 2. 資料庫維護（自動補件排程）
在第一次執行系統前，或需要向資料庫同步最新歷史股價數據時，請於終端機執行：

```bash
python insert_data.py
```

### 3. 啟動服務 (本地端)
*   **啟動回測網頁主介面**：
    ```bash
    streamlit run app.py
    ```
*   **開啟獨立數據稽核後台**：
    ```bash
    streamlit run view_db.py
    ```

## ☁️ 雲端部署說明 (以 Render.com 為例)

本專案已完全做好雲端部署優化：
1.  在 Render 建立一個全新的 **Web Service**並連結您的 GitHub 儲存庫。
2.  **環境設定**：
    *   **Runtime**: `Python 3`
    *   **Build Command**: `pip install -r requirements.txt`
    *   **Start Command**: `streamlit run app.py`
3.  **字體與圖表自動化**：Render 部署時會自動讀取 `packages.txt` 並透過 `apt-get` 安裝 `fonts-noto-cjk` 系統字型，免去手動微調 Linux 字體檔的繁瑣流程，圖表一上線即完美顯示中文。
4.  **環境變數**：記得在 Render 的 `Environment` 設定中填入您的 `DB_URL` 與 `TICKERS`。

## 💡 使用指南 (主程式)

1.  **設定標的與區間**：在網頁頂端選擇您要測試的股票標的，並拉選回測的開始與結束日期。
2.  **自訂策略邏輯**：在「步驟一」面板中勾選技術指標（支援 And 聯集聯動），並決定該指標要實施「正向（做多）」或「反轉（做空）」策略。
3.  **微調參數與掃描**：在「步驟二」面板微調參數滑桿。接著在下方選單選定你想進行窮舉優化的「參數掃描目標」。
4.  **執行與分析**：點擊「🔥 開始執行完整回測與參數掃描」按鈕。系統將輸出最佳參數提示、累積報酬率對抗曲線 (vs 大盤)、參數掃描期望值優化曲線與詳細回測數據表格。
5.  **底層數據觀測**：在最下方的觀測站選擇特定標的，即可查閱逐日的底層數據與指標細節。
